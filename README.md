# 소소한 생활 여행

작은 놀이공원이 문을 열었어요. 그럼, 즐거운 시간 되시길 바랍니다!

입구에서 입장권을 내고 들어가면 놀이공원 지도가 나와요. 놀이기구를 눌러 구경하면 돼요.

| 놀이기구 | 코너 | 내용 |
| --- | --- | --- |
| 통장 롤러코스터 | 질러봤어요 | 잘 산 것, 후회한 것. 찐템 / 쏘쏘 / 텅장 주의 |
| 꿀팁 하우스 | 이렇게 살아요 | 지켜보니 좋았던 생활 규칙 |
| 시상식 무대 | 멋대로 시상해봤어요 | 심사위원은 저 혼자인 시상대 |
| 밤의 점술 텐트 | 인생 스포당해봤어요 | 사주 예시, 방문자 사주 보기, 운영자와의 케미 |

## 실행

빌드 과정 없이 `index.html` 하나로 돌아가요. 파일을 브라우저로 열거나 GitHub Pages로 배포하면 돼요.

- 링크 끝에 `#map`, `#bought`, `#rule`, `#tier`, `#saju`를 붙이면 그 화면부터 열려요.
- 밤의 점술 텐트의 사주 계산은 방문자 브라우저 안에서만 이뤄지고, 입력한 생년월일은 저장하거나 전송하지 않아요.

## 사주 계산 기준

- 양력 생년월일 기준, 절기로 년주와 월주를 나눠요 (태양 황경 계산, 오차 약 10분).
- 한국 표준시 30분 보정 후 시주를 정하고, 밤 11시 30분 이후는 다음 날 자시로 봐요.
- 오행 비중: 천간 10점씩, 지지는 지장간 비율대로, 태어난 달은 계절 기운이라 30점.
